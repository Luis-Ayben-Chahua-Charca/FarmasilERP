## Descripción
Script en `scripts/` que crea una base de prueba con volumen realista (por ejemplo, 300 productos con 2 a 4 lotes cada uno) y mide el tiempo de respuesta de la búsqueda de stock. Nunca se usa la base real de la farmacia. Registrar el resultado en un comentario de este issue para que QA lo use en {{TQ-S2}}.

## Criterios de aceptación
- [ ] El script genera la base de prueba en una ruta distinta de `datos/farmasil.db`.
- [ ] La búsqueda responde en menos de 2 s con ese volumen.
- [ ] El resultado de la medición queda comentado en el issue.

## Dependencias
- {{HU-08.1}} API de consulta de stock
- {{HU-08.2}} Pantalla W3
