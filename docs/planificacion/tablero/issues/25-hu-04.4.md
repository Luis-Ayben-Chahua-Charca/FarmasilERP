## Descripción
Formulario con selector de producto (desde `GET /api/productos`), número de lote, fecha de vencimiento, cantidad y botón **Registrar ingreso**. Al guardar, confirmación visible y formulario limpio. Campos grandes y etiquetas claras (RNF-04). Referencia: boceto en `docs/diseno/`. Módulo en `app/public/js/pantallas/` (exporta `titulo` y `render(contenedor)`), llamadas con `api.js`, textos en español, sin librerías externas ni CDN.

> Integrar esta tarea primero: {{HU-04.5}} y {{HU-04.6}} modifican el mismo archivo y deben partir de `main` actualizado.

## Criterios de aceptación
- [ ] Un ingreso registrado desde la pantalla aumenta el stock del producto.
- [ ] La pantalla coincide con el boceto `docs/diseno/w2-ingreso-lote.html`.
- [ ] No hay peticiones a recursos externos (pestaña de red).

## Dependencias
- {{HU-04.1}} API de ingreso de lote
- {{HU-04.2}} API de productos
