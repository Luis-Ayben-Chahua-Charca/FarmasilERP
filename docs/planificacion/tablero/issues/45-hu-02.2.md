## Descripción
Pruebas con Supertest de que `POST /api/ventas` descuenta según la regla de HU-02 y que `GET /api/stock` lo refleja por lote. Complementa las pruebas unitarias de {{HU-02.1}}: allí se prueba la función sola; aquí, la venta completa contra una base en memoria. Archivo aparte: `test/ventas-lotes.test.js`. Si algo falla, se registra un issue `bug` y se avisa a Luis (dueño de HU-02).

## Lo que ya existe
- `asignarLotes` ({{HU-02.1}}) y `POST /api/ventas` ({{HU-01.2}}).
- `GET /api/stock` devuelve los lotes con su `cantidad` disponible, ordenados por vencimiento.

## Criterios de aceptación
- [ ] Lote A (2027-03-31, 4 u.) y B (2027-11-30, 100 u.); venta de 6 → la respuesta trae A 4 y B 2, y `GET /api/stock` muestra A 0, B 98 y total 98 (HU-02 CA1).
- [ ] Con A en cero, una segunda venta de 3 → solo usa B (B 95); no se crea ninguna `linea_venta` para A (HU-02 CA2).
- [ ] Lote registrado **después** pero que vence **antes** → se usa primero.
- [ ] Dos productos en la misma venta → cada uno descuenta solo de sus propios lotes.
- [ ] `npm test` pasa.

## Dependencias
- {{HU-01.2}} API de registro de venta
