## Descripción
En cada fila de W4, el botón **«Editar»** abre los datos del producto en la misma fila o en un formulario junto a ella, con los cuatro campos. Al guardar envía `PUT /api/productos/:id` (contrato en `docs/arquitectura/api-reportes.md`, sección 1).

Cambiar el precio toma **tres acciones como máximo**: 1) Editar, 2) escribir el precio, 3) Guardar. Con `200` se muestra «Precio actualizado: <producto>, S/ 0.60. Rige para las ventas nuevas.» y la fila se actualiza. Con `400` el aviso sale bajo el campo y se conserva lo escrito. «Cancelar» cierra la edición sin cambios. Se usa la misma `validarProducto` de `js/productos.js` ({{HU-06.4}}).

## Lo que ya existe

## Criterios de aceptación
- [ ] El precio de un producto se cambia en tres acciones como máximo y queda vigente (HU-06 CA3).
- [ ] Después del cambio, una venta nueva en W1 usa el precio nuevo; las ventas anteriores no cambian.
- [ ] Un precio inválido muestra el aviso bajo el campo y el producto no cambia.
- [ ] «Cancelar» deja la fila como estaba.
- [ ] F12: consola sin errores; la respuesta tarda menos de 2 s.
