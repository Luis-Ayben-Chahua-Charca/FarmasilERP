## Descripción
La restricción `UNIQUE (producto_id, numero_lote)` ya existe en `001_esquema_inicial.sql`. Capturar el error de SQLite en `POST /api/lotes` y responder `409` con un mensaje del tipo «El lote L-2309 ya está registrado para este producto». El mismo número de lote en otro producto se acepta. Errores con código HTTP y cuerpo `{ "error": "mensaje en español" }`, formato que ya espera `app/public/js/api.js`. Precios en céntimos enteros y cantidades por unidad.

## Criterios de aceptación
- [ ] Segundo ingreso del mismo lote para el mismo producto: `409` y el stock no cambia.
- [ ] El mismo número de lote en otro producto: `201`.

## Dependencias
- {{HU-04.1}} API de ingreso de lote
