## Descripción
Agregar a la alta rápida «+ Nuevo producto» de W2 un selector obligatorio **Tipo**, con las opciones «Genérico» y «Comercial» (valores `generico` y `comercial`), y enviarlo en `POST /api/productos`. Si no se elige, el formulario no se envía y aparece bajo el campo: «Elija si el producto es genérico o comercial.» La API ya acepta `tipo`; esta tarea va **antes** que {{HU-07.2}}, que lo vuelve obligatorio en el servidor, para no dejar W2 sin poder crear productos.

## Lo que ya existe
- Alta rápida en `w2-ingreso-lotes.js` (`camposAlta`, `validarProducto`, `guardarProducto`).
- `POST /api/productos` valida `tipo` contra `generico`/`comercial` y devuelve `campo: "tipo"` (#37).
- Avisos junto al campo (`marcarError`), de #41.

## Criterios de aceptación
- [ ] El alta rápida muestra el selector Tipo con «Genérico» y «Comercial», sin opción elegida por defecto.
- [ ] Sin tipo, al presionar Guardar no se envía nada y aparece el aviso bajo el selector (HU-07 CA3).
- [ ] Con tipo elegido, el producto se guarda con ese tipo (se comprueba con el filtro Tipo de W3).
- [ ] F12: consola sin errores.
