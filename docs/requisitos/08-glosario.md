# 08 — Glosario

| Término | Definición |
|---|---|
| **Acción terapéutica** | Categoría según el efecto del medicamento (digestivo, respiratorio, cardíaco, etc.). Organiza los productos comerciales. |
| **Comercial (producto)** | Medicamento de marca. Se organiza por acción terapéutica. |
| **DIGEMID** | Dirección General de Medicamentos, Insumos y Drogas del Perú. Regula precios y el control sanitario. |
| **Genérico (producto)** | Medicamento identificado por su principio activo. Se ordena alfabéticamente. |
| **Ingreso de lote** | Registro de la mercadería recibida: producto, número de lote, fecha de vencimiento y cantidad. |
| **Lote** | Conjunto de unidades de un producto con un mismo número de lote y fecha de vencimiento. |
| **PMV** | Producto Mínimo Viable: versión del sistema con lo mínimo necesario para aportar valor. Fecha objetivo: 3 de diciembre de 2026. |
| **POS** | Terminal de punto de venta existente; cobra con tarjeta, Yape o Plin e imprime boletas. No se integra con el sistema. |
| **Propietaria / Administradora** | Dueña del negocio; usuaria con acceso a todas las funciones. |
| **Stock** | Cantidad disponible de un producto: suma de ingresos de lotes menos ventas. |
| **Técnica farmacéutica** | Personal de atención en mostrador; usuaria de ventas y consultas. |
| **Vencimiento más próximo (FEFO)** | Regla de descuento de stock: primero sale el lote que vence antes (*First Expired, First Out*). |
